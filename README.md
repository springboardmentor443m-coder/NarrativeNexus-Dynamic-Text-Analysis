# NarrativeNexus — Dynamic Text Analysis (Starter)

Quickstart:
1) Create venv: `python -m venv .venv` and activate it.
2) `pip install -r requirements.txt`
3) Run: `streamlit run app/app.py`

Features: upload/paste → preprocessing → topics (NMF) → sentiment (VADER) → extractive summary → JSON report.
